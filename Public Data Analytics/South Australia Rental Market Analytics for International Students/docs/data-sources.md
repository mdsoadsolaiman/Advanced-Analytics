# Data Sources

## Primary Source

[South Australian Government Data Directory — Private Rent Report](https://data.sa.gov.au/data/dataset/private-rent-report)

## Source Workbooks

The repository preserves six source workbooks:

- `private-rental-report-2020-12.xlsx` — 2020 Q4
- `private-rental-report-2021-12.xlsx` — 2021 Q4
- `private-rental-report-2022-12.xlsx` — 2022 Q4
- `private-rental-report-2023-12.xlsx` — 2023 Q4
- `private-rental-report-2024-12.xlsx` — 2024 Q4
- `private-rental-report-2025-12.xlsx` — 2025 Q4

The source workbooks include notes describing the underlying rental-bond data, suppression of small counts, rounding and the definition of the metropolitan area.

No dataset licence is asserted in this repository documentation. Users should consult the source directory and individual source resources for applicable terms.
