# Advanced Analytics Portfolio

Business Analytics, Public Data Analytics and Statistical Research Analytics

## Overview

This collection contains five completed analytics projects organised into three specialist areas: Business Analytics, Public Data Analytics and Statistical Research Analytics. Together, the projects demonstrate analytical decision support, data visualisation, statistical modelling, interactive applications and professional reporting.
